Abstract

The nano4M model supports any-to-any generation across four modalities: RGB, Depth, Surface normals, and Scene description. We extend it with a fifth modality: Canny edges, enabling generation from and to edge maps, as well as their use as an intermediary conditioning step in chained generation pipelines.

I. Introduction

The current nano4M model supports any-to-any generation across four modalities: RGB, Depth, Surface normals, and Scene description. However, direct generation from Scene description to RGB suffers from notable quality degradation, including missing objects, incorrect shapes, and inconsistent spatial positioning. We hypothesize that this stems from the lack of an intermediate structural modality that grounds spatial and geometric information before generating the RGB image.

To address this, we extend nano4M with a fifth modality: Canny edges [1]. This modality provides a lightweight, deterministic representation of object boundaries and spatial layout. Our hypothesis is that introducing this modality enables higher-quality chained generation (Scene description → Canny edges → RGB), where the edge map serves as a structural intermediary constraining object shape and position before texture and color are generated.

II. Related Work


4M: Massively Multimodal Masked Modeling [2]

The 4M framework shows that training a single transformer on diverse tokenized modalities enables any-to-any generation. Our nano4M model is a lightweight reproduction of this framework, which we extend by adding Canny edges as a fifth modality without architectural changes.

Segment Anything (SAM) [3]

SAM is a large-scale promptable segmentation foundation model trained on over 1 billion masks, designed to transfer zero-shot to new tasks including edge detection. We leverage its automatic mask generation as a preprocessing step before applying the Canny detector, yielding significantly cleaner edge maps than direct RGB-based detection.

III. Method

III-A. Canny edges generation

We generated the Canny edge modality from the RGB CLEVR [4] dataset using the OpenCV Canny() function [7]. Applying it directly on RGB images yielded noisy or under-detected results. We therefore first applied SAM to produce object masks, then ran the Canny detector on these masks, yielding sharper and cleaner boundaries.

III-B. Dataset tokenization

We tokenized all splits using the pretrained 4M DiVAE tokenizer (codebook size 8k, 196–1024 tokens/image). The Cosmos [6] tokenizer used for other modalities was unsuitable as it was designed for RGB images and yielded poor reconstructions of binary edge maps.


Comparison between Cosmos and DiVAE reconstruction.

III-C. Model Training

Training required no architectural changes. The only code modification was adapting SimpleMultimodalDataset to load Canny tokens from a separate path via a new modality_paths argument. Training ran for 5h 35m on 2 NVIDIA L40S GPUs, versus 4h 45m for the four-modality baseline.

Curves during training.

III-D. Evaluation Setup

After training, we performed a hyperparameter search specifically for the Canny → RGB generation task. We generated 900 RGB images by varying four decoding hyperparameters (top-p, top-k, temperature, number of steps) and selected the best configuration through visual inspection. The best configuration found was: steps = 8, temperature = 0.1, top-p = 0.0, top-k = 2.

Using these fixed hyperparameters, we generated 5,000 RGB images conditioned on Canny edge tokens from the test set and evaluated quality using FID [5], which measures distributional similarity between generated and real images via deep features extracted by an Inception-v3 network. For comparisons with other modalities, we used: steps = 8, temperature = 0.01, top-p = 0.2, top-k = 0, applied to both direct modality → RGB and chained modality → Canny → RGB pipelines.

Example of RGB image generated from a canny edge map (steps=8, temp=0.1, top_p=0.0, top_k=2). Such generated images were used to compute the FID score.

IV. Experiments

IV-A. FID testing

We generated 5,000 RGB images per conditioning modality and measured FID against the CLEVR test set. Depth and normal give the best results (FID 35.15 and 34.26). Canny edges are surprisingly competitive (50.59), while scene description struggles (113.33) - text simply lacks the spatial detail needed for accurate generation.

Adding Canny as an intermediate step (modality → Canny → RGB) does not help: it slightly hurts quality for depth and normal, and only marginally improves scene description (~2 FID points). Canny edges don't seem to add information that depth and normal don't already provide.

IV-B. Spatial Coherence Analysis

Along the quantitative testing that was carried out using the FID metric, we also tested the spatial coherence of our model by feeding synthetic Canny inputs (shapes moving and scaling across the canvas) to the model to generate RGB images. In general the results are satisfying and the model behaves as expected. The RGB images contain objects similar to the ones from the CLEVR dataset, of coherent sizes and at the right position.

Spatial Coherence Analysis: comparison of canny edges inputs and resulting RGB images

However, this visualisation also allowed us to spot two limitations of our model. The first is that when the canny edges used as input are located too low or too high on the canvas, the resulting image is usually empty. This behavior is most likely caused by the dataset used to train our model. Indeed all the images from the CLEVR dataset depicts objects at various positions but the top part of the background is always white and the bottom grey. Therefore our model is conditioned to output similar results in these zones.


Moreover, the resulting shape is not always coherent. When using a square or circle shape as the canny edges input we often see a cylinder shape in the generated image. This could be a result of using SAM masking in our tokenization pipeline. While this step helped us to get rid of most of the noise, it also got rid of some important segments that are edges in 3D but not on the 2D images which results in a loss of conditional information for the model to determine the geometric shape.

As stated above, placing the canny edges too low or too high on the canvas often result in an empty RGB generation.

V. Conclusion

We successfully extended nano4M with a fifth modality: Canny edges. The model can now generate to and from edge maps, and use them as an intermediate step in chained generation pipelines. With a FID of 50.59, Canny edges prove to be a reasonable conditioning signal, not far behind depth and normals. The spatial coherence analysis also confirmed that generated RGB images follow the structure of the input edge maps well.

That said, our initial hypothesis did not fully hold. Chaining Canny edges between Scene description and RGB only brought a marginal improvement of about 2 FID points, suggesting that edge maps alone are not sufficient to compensate for the lack of geometric detail in text descriptions. We also noticed that the model tends to generate cylinders regardless of the input shape, and produces empty backgrounds when objects are placed near the image borders, likely because CLEVR training images consistently place objects in the center.

Future work could explore training on more diverse datasets, or richer intermediate modalities such as segmentation maps that may carry more structural information.
